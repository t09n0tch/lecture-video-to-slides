# 출력 검수

## 원본과 해설

- 원본 이미지의 가로세로 비율을 유지하고, 수식·화학 결합·전하·그리스 문자·필기를 자르지 않는다. 원본에 이미 있는 잘림이나 겹침을 새로 생긴 문제와 구별한다.
- 손필기는 원본에 남기고 핵심 의미를 텍스트로 설명할 수 있다. 판독하기 어려운 손필기를 임의로 확정하지 않는다.
- 원본 이미지가 너무 작아지면 해설을 줄이거나 다른 배치로 바꾼다. 그림보다 설명 영역을 우선해 원본을 읽기 어렵게 만들지 않는다.
- 구두 설명을 그대로 길게 전사하기보다 각 페이지의 학습 포인트를 요약한다. 시약·약물·고유명사·수치·단위·조건은 화면과 대조한다.
- 최종 PPTX와 PDF는 같은 버전의 데이터로 만든다. 내용 수정 후에는 두 파일을 함께 다시 출력한다.

## 글꼴과 PDF

한글, 영문, 숫자, 기호를 지원하는 실제 설치 글꼴을 선택한다. PPTX에서 정상이어도 PDF의 임베딩 글꼴은 일부 기호를 지원하지 않을 수 있다.

1. 실제로 사용하는 글리프를 확인한다. 아래첨자 `₂ ₃ ₄ ₅ ₆`, 위첨자, `α β`, 전하와 도 기호를 특히 점검한다.
2. 원본 PNG나 PPTX 미리보기뿐 아니라 **최종 PDF의 렌더링**에서 네모 상자·누락·대체 글꼴을 확인한다. 텍스트 추출 성공만으로 글리프 표시를 통과 처리하지 않는다.
3. 문제가 있으면 해당 글리프를 지원하는 글꼴 또는 네이티브 아래첨자 서식을 사용한다. 문맥상 명확한 경우 해설의 화학식을 일반 숫자로 표기할 수 있지만 수학의 아래첨자 의미를 평문 숫자로 바꾸지는 않는다. 원본 구조식 이미지는 보존한다.
4. PDF의 추가 해설은 가능한 한 선택·검색 가능한 텍스트로 유지한다. 이미지 PDF만 가능한 환경이면 그 제한을 밝힌다.

저작 도구의 PDF 내보내기에 런타임 오류가 있으면 현재 환경의 의존성과 공식 기능부터 확인한다. 특정 과거 런타임의 모듈 별칭 패치를 항상 실행하는 규칙으로 만들지 않는다. 필요하면 검증된 로컬 PPTX→PDF 변환 도구를 사용하고 변환 결과를 다시 확인한다.

## 전달 전 확인

모든 페이지를 개별 크기로 보고, 원본 내용의 보존·한국어 해설의 맞춤·본문 범위·순서를 확인한다. 전체 접촉 시트만 보고 개별 페이지 검수를 대신하지 않는다. 같은 이미지와 데이터를 사용하는 경우에도 PDF와 PPTX의 글꼴 처리가 다를 수 있다.

완료 조건은 요청한 파일의 실제 존재, 올바른 페이지 수, 읽을 수 있는 원본, 편집 가능한 PPTX 해설, 포함된 발표자 노트, 정확한 시간 연결, 그리고 최종 PDF의 정상 표시이다. 원본 이미지 속 글자까지 편집 가능하다고 설명하지 않는다.
